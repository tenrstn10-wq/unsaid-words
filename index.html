📖 Buku Panduan Penggunaan

Panduan lengkap dan praktis cara mengoperasikan seluruh fitur dalam aplikasi:

  • 1. Mengganti Lagu & Foto Sampul:
    • Ketuk ikon musik 🎵 kecil di pojok kanan bawah sampul album untuk mengunggah dan memutar file lagu MP3 pilihanmu.
    • Ketuk langsung gambar sampul album utama untuk mengganti foto utamanya sesuai keinginan.
  • 2. Galeri Polaroid & Interaksi Foto:
    • Acak Posisi: Ketuk tombol "Acak" di bagian atas galeri untuk mereset dan mengacak tata letak kartu polaroid secara otomatis agar kembali rapi.
    • Download Semua: Ketuk tombol "Download" di atas galeri untuk menyimpan seluruh tampilan layar galeri polaroid beserta background blur-nya sekaligus sebagai satu gambar PNG beresolusi tinggi.
    • Tambah Foto Baru: Ketuk tombol "Tambah" di bagian atas galeri untuk memasukkan foto baru dari perangkatmu.
    • Navigasi & Transformasi: Geser layar untuk menjelajah, gunakan dua jari untuk memperbesar/mencubit (*pinch-to-zoom*) atau memutar (*rotate*) foto, dan satu jari untuk menggeser posisi gambar di dalam bingkai.
    • Sisi Belakang Kartu: Ketuk 2 kali secara cepat pada bagian depan kartu untuk membalik ke belakang. Kamu bisa mengetik langsung nama pada kolom (Isi Nama), menulis pesan rahasia, dan mengubah stempel tanggal sesuai keinginan!
  • 3. Sinkronisasi & Edit Lirik:
    • Masuk ke tab "Lyrics Edits" di halaman utama.
    • Masukkan teks lirik baru baris per baris, putar lagu, lalu ketuk tombol "Rekam Baris Ini" pas di ketukan vokal penyanyi agar waktunya sinkron otomatis.
  • 4. Mode Layar Bersih (HIDE / SHOW):
    • Tekan tombol "HIDE" di bagian bawah untuk menyembunyikan semua menu secara sinematik dan menikmati tampilan visual pemutar musik secara penuh.
    • Tekan tombol "SHOW" untuk memunculkan kembali seluruh menu navigasi.
